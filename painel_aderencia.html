Como salvar (simples): o painel salva sozinho no seu navegador a cada clique — você não precisa fazer mais nada no dia a dia. O “Baixar backup” gera um arquivo do seu histórico (guarde ou leve para outro computador com “Restaurar”).
Sobre o GitHub: o arquivo do painel fica no GitHub só para hospedar a ferramenta — você o coloca lá uma única vez. Não precisa “comitar” toda semana; os dados vivem no seu navegador.
Lógica: monitore sinais, não pessoas. Atenção só no amarelo e no vermelho. O 1:1 é quinzenal — nas semanas sem 1:1, deixe em “—”.
