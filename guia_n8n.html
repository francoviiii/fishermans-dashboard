Como ligar as automações no n8n

Passo a passo para o Dashboard da Equipe e o Acompanhamento dos Planos se atualizarem sozinhos com o ClickUp. Feito para seguir sem saber programar — é só copiar e colar.
A ideia em uma frase: o n8n é um robô que, de tempos em tempos, lê o seu ClickUp e regrava um arquivo (dados_planos.json) no GitHub. A página lê esse arquivo e mostra atualizada. Você configura uma vez; depois roda sozinho.
1

Pegar as 3 chaves

~10 min

Antes de mexer no n8n, junte estas três coisas num bloco de notas:

A · Token do ClickUp
  1. No ClickUp, clique no seu avatar (canto inferior esquerdo) → Settings.
  2. No menu, vá em Apps.
  3. Em "API Token", clique Generate (ou Copy). Vai começar com pk_.
ClickUp Token: pk_xxxxxxxxxxxxxxxxxxxx
B · Token do GitHub
  1. No GitHub, clique na sua foto (canto superior direito) → Settings.
  2. Desça o menu da esquerda até o fim: Developer settings.
  3. Personal access tokens → Tokens (classic) → Generate new token (classic).
  4. Dê um nome (ex.: "n8n"), marque a caixa repo e clique Generate token.
  5. Copie o código (começa com ghp_). Ele só aparece uma vez — guarde bem.
GitHub Token: ghp_xxxxxxxxxxxxxxxxxxxx
C · Nome do repositório

É o "usuário/repositório" que você criou no GitHub. Ex.: se seu usuário é vivianef e o repositório governanca-shrigma:

Repositório: vivianef/governanca-shrigma
Importante: suba o pacote no GitHub antes — o arquivo dados_planos.json já vem no pacote, e o robô precisa que ele já exista lá pra conseguir regravar.
2

Criar a conta no n8n

~5 min
  1. Acesse n8n.io → Get started (a opção Cloud tem teste grátis e é a mais fácil — não precisa instalar nada).
  2. Crie a conta e entre. Você vai cair no painel do n8n.
  3. Clique em Create Workflow (novo fluxo). É uma tela em branco onde a gente vai encaixar as "peças" (nós).

Cada "nó" é uma caixinha. Você adiciona clicando no + e liga uma na outra com uma linha. Vamos montar 5 caixinhas em sequência.

3

Montar o robô do Acompanhamento (5 nós)

o principal

Adicione os nós na ordem abaixo, ligando um no outro. Onde diz "cole", use as chaves do Passo 1.

1. Schedule Trigger agendamento
Procure por Schedule Trigger. Configure para rodar, por exemplo, toda segunda às 07:30. (É a peça que dá a partida sozinha.)
2. HTTP Request ler o ClickUp
Adicione HTTP Request. Preencha: Method: GET URL: https://api.clickup.com/api/v2/list/901327080406/task Em Headers → Add: nome Authorization, valor = seu token do ClickUp.
Em Query Parameters → Add: include_closed = true.

O número 901327080406 é a sua lista Viviane — já está certo.

3. HTTP Request ler o arquivo no GitHub
Outro HTTP Request: Method: GET URL: https://api.github.com/repos/SEU-USUARIO/SEU-REPO/contents/dados_planos.json Em Headers → Add dois: Authorization = Bearer + seu token do GitHub; e User-Agent = n8n.

Isso pega o "sha" (a versão atual do arquivo), que o GitHub exige pra deixar regravar.

4. Code transformar
Adicione um nó Code e cole o conteúdo do arquivo n8n_automacao_planos.md (seção "Transformar") — ou a versão simples que traz o status de cada task e a observação escrita na descrição começando com Obs:.
5. HTTP Request gravar no GitHub
Último HTTP Request: Method: PUT URL: https://api.github.com/repos/SEU-USUARIO/SEU-REPO/contents/dados_planos.json Mesmos Headers do nó 3 (Authorization + User-Agent). Em Body (JSON), use a mensagem, o content e o sha que o nó Code preparou (o modelo exato está no .md).
Dica de ligação: a linha vai do 1 → 2 → 3 → 4 → 5. O nó Code (4) usa o que veio do ClickUp (2) e do GitHub (3).
4

Testar

~3 min
  1. Clique em Test workflow (ou "Execute") no n8n. Cada caixinha deve ficar verde.
  2. Se der erro numa caixinha, ela fica vermelha — clique nela e confira o token/URL daquele nó.
  3. Abra o seu site no GitHub e o Acompanhamento dos Planos: em vez de "aguardando 1ª sincronização", ele deve mostrar "sincronizado do ClickUp" com a data.
Erro comum: "Bad credentials" = token do GitHub errado ou sem a permissão repo. "Team not authorized"/"Oauth" = token do ClickUp errado. É quase sempre a chave colada com um espaço a mais.
5

Deixar rodando sozinho

~1 min

No canto superior do fluxo, vire a chave Active (Inativo → Ativo). Pronto: toda segunda ele roda sozinho e atualiza o painel.

No dia a dia: você só mexe no ClickUp — muda o status da task e, se quiser observação, escreve na descrição começando com Obs:. O resto é automático.
6

Repetir para o Dashboard da Equipe

igualzinho

É o mesmo fluxo, mudando só duas coisas:

  • No nó 2 (ClickUp), a URL passa a buscar as tarefas da equipe toda por período — veja n8n_automacao_dashboard.md.
  • Os nós 3 e 5 (GitHub) apontam para dados_equipe.json em vez de dados_planos.json.

Pode duplicar o primeiro fluxo (Duplicate) e só trocar esses pontos — mais rápido que montar do zero.
